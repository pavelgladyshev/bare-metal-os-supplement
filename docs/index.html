Operating Systems from the Bare Metal Up

Building logOS on a simulated RISC-V computer

Pavel Gladyshev

This book teaches operating systems by building one. It starts with a small RISC-V computer that you can inspect down to the gates, and climbs from the hardware upwards: assembly language and C with nothing underneath, then a file system, system calls and a shell, then processes, interrupts and pipes, and finally virtual memory and protection. Along the way a small Unix-like system, logOS, grows through three versions, and every listing in the book is code you can build, run and change.

Set up your computer

Everything runs on your own computer with free software: on a Mac in the Terminal, on Ubuntu or Debian Linux, and on Windows in Ubuntu under WSL 2. A script that comes with logOS installs the RISC-V compiler and Java, fetches the simulator, builds logOS and checks that it boots.

  1. macOS: install Homebrew. Windows: run wsl --install -d Ubuntu-24.04 in PowerShell, restart, and open Ubuntu from the Start menu.
  2. Fetch logOS and run its set-up script: 
    git clone -b 2.x-blackrock https://github.com/pavelgladyshev/logos.git
cd logos
./setup.sh
  3. When the script says Ready, type make run to start logOS in the terminal (Ctrl-C stops it), or make gui to watch the computer in the simulator's window.

The code

  • logOS, the operating system, in three branches: 1.x-belfield, 2.x-blackrock and 3.x-glendalough.
  • The supplement: the smaller example programs and circuits (RARS programs, the Pong game in four versions, and the multiprocessor examples for QEMU).
  • Logisim Evolution UCD, the simulator of the computer, and the modified RARS used for the first assembly programs.
