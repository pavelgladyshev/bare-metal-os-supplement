A lecture plan

Operating Systems from the Bare Metal Up in twelve weeks

Back to the book's page

The book was written for a module of twelve weeks with two lectures a week. This plan fits it into those 24 lectures. For each lecture it names the core sections, which later chapters build on, and the sections that can be left for reading. Every chapter's “In real systems” section, its history boxes and Appendices A and B are reading throughout. Section numbers are those of the book.

Chapter 2 (first steps with the tools) and Appendix C (setting up) belong in the first laboratory session rather than a lecture, and Chapter 10 (shell scripting) and Appendix F in private study. Chapter 22 (multiprocessors) can replace Lecture 23 for a class with more interest in hardware than in security.

Laboratory sessions

Each chapter's exercises are tagged by kind: Understand, Trace, Linux, Modify, Measure, Design and Project. The Modify and Project exercises on Blackrock and Glendalough can be checked against the test suites of Appendix D, which makes them suitable for assessed laboratory work.
